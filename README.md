# AI Resume Screening System

## Project Overview
The AI Resume Screening System is a Machine Learning and Artificial Intelligence based application designed to automate the resume screening process. The system analyzes resumes and predicts whether a candidate is suitable for a particular job role based on skills, education, experience, and keywords present in the resume.

This project helps reduce manual effort in recruitment and improves hiring efficiency using AI techniques.

---

## Objectives
- Automate resume screening process
- Analyze resumes using AI and NLP techniques
- Match candidate skills with job requirements
- Reduce manual recruitment workload
- Improve candidate shortlisting accuracy
