Resume Screening API
Overview

A machine learning–based API that classifies resumes into job categories using NLP techniques. It helps automate and speed up the recruitment screening process.

Features
Resume classification
NLP-based text processing
Fast and efficient prediction
Tech Stack

Python, Flask/FastAPI, Scikit-learn, Pandas, NLP, TF-IDF

How It Works
Extracts and preprocesses resume text
Converts text using TF-IDF
Predicts job category using ML model
API

POST /predict
Input: Resume text/file
Output: Predicted job category

Conclusion

This project showcases the use of machine learning in automating resume screening for efficient hiring.
